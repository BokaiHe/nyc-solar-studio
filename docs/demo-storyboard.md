# 演示分镜

`npm run demo:record` 在独立的浏览器环境里操作真实界面（默认英文，`DEMO_LANG=zh` 为中文），所有数字都由应用实时计算，脚本不替换任何结果。导览被标记为已看过，草稿被清空，因此每次录制都从同一个起点开始。

| 时间 | 操作 | 展示的内容 |
|---|---|---|
| 0–8 s | 在全市地图上输入 "180 7th Avenue Brooklyn"，选中第一个结果 | 地址搜索、地图飞到 P.S. 321、选中轮廓和建筑信息 |
| 8–11.5 s | 点击 Design this roof | LoD2 三维屋顶和 200 m 内的周边建筑 |
| 11.5–14 s | 打开 Satellite 和 Plan view | 2014 年航拍铺在屋面和地面上，正交俯视 |
| 14–18.5 s | 点击 Detect keep-out areas | U-Net 在浏览器里识别楼梯间和排风口，框成禁装区 |
| 18.5–23 s | 点击 Generate array | 避开禁装区和退距的阵列 |
| 23–29 s | 回到 3D，日期设为冬至，从 11:00 播放 | 周边建筑在冬至下午投下的阴影（16:30 左右日落，播放停在 14:30 左右） |
| 29–32.5 s | 时间回到 13:00，打开 Show annual panel yield | 组件按全年发电量着色 |
| 32.5–38 s | 进入 Results | 容量、年发电量、减碳和电费 |

时间是展示用的节奏，不是计算耗时。录制从地图首屏加载完成后开始，所以不需要裁掉启动画面。每一帧都来自 Chrome DevTools 截屏流，带有时间戳；FFmpeg 按时间戳重建恒定 60 fps 的视频，保留真实的动作节奏。每段开始的实际时间记录在 `docs/demo-recording.json` 里。原始帧约 1 GB，默认写在系统临时目录，可以用 `DEMO_TMP` 指到空间充足的磁盘；录制成功后自动删除。识别、生成或渲染太慢导致超时，或者页面报错时，脚本会直接失败，不会产出不完整的录像。

README 的预览动画由 `scripts/encode-webp.py` 用 Pillow 编码成动态 WebP。Pillow 会插入关键帧；FFmpeg 的动态 WebP 编码器不插关键帧，有损误差会累积成条纹。`npm run readme:screenshots` 在每段结束前的稳定画面处，从视频中抽取 README 截图。
